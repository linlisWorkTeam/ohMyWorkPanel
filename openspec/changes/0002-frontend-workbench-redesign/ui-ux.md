# UI / UX 设计规格

## 1. 视觉方向与优先级
「安静的协作控制台」：正文与任务证据优先，Agent 姓名、角色、当前工作始终可辨。默认保留用户当前主题，初次使用沿用现有默认值；深色主题作为主评审样例，atlas/minimal 不强制改深色。像素元素只出现在场景及小型头像叙事，不装饰表单/正文。
主操作每个上下文最多一个高强调按钮；待审批与失败使用语义色和文字，不以整屏高饱和卡片竞争。不得暗示云同步或提供不存在的全局智能搜索。

## 2. 信息架构与页面范围
| 层级 | 导航 | 内容 / 返回位置 |
|---|---|---|
| 全局 | 群列表、Agent 环境、可观测、设置 | 不重置当前群消息位置；管理员操作按权限 |
| 群头 | 名称、project/chat、工作区摘要、连接、公告、群设置 | 工作区路径截断，复制/详情可见完整服务器路径 |
| 群导航 | 协作、交付、目标、内容、场景、扩展 | 群内切换；chat 群不显示交付/目标/内容项目入口 |
| 上下文右栏 | 成员、队列、详情 | 选消息/run/成员只换详情内容；不抢走主页面 |
| 高风险操作 | 成员永久删除、清空日志、停止 Goal、发布、灰度 | 各资源详情内确认，不做全局一键执行 |

全局群筛选仅对已加载列表按名称匹配。当前权限不可用的入口给静态原因；只有对当前角色完全不适用的管理导航可隐藏。待审批计数仅表示已加载群数据，不宣称全平台待办聚合。

## 4. 颜色角色与组件状态
| UI 角色 | 稳定 token |
|---|---|
| 应用/侧栏/内容/浮层 | --lp-bg-app / --lp-bg-sidebar / --lp-bg-panel / --lp-bg-elev |
| 文本/次要/辅助 | --lp-text / --lp-text-dim / --lp-text-faint |
| 分隔/重点边界/聚焦 | --lp-border / --lp-border-strong / --lp-ring |
| 主操作/文字 | --lp-accent / --lp-text-invert |
| 成功/警告/失败 | --lp-success / --lp-warn / --lp-error |
| 悬停/选中/禁用 | --lp-bg-hover / --lp-bg-active / --lp-disabled-bg + --lp-disabled-text |
| 用户/Agent 消息 | --lp-bubble-user / --lp-bubble-ai |

不新增颜色字面量，不改语义 token 名称或 data-theme。七套 palette 的具体值以 src/shell/tokens.css 为准，语义映射以 src/themes.css 为准；主色不代表唯一可用状态色。对比度不合格时在实现评审中调整 token 映射并单独记录，不以「沿用主题」代替检查。

| 组件 | default / hover / focus / disabled / loading / error |
|---|---|
| 主按钮 | accent/invert；hover增加边框；focus 2px ring+2px offset；disabled语义色并不可提交；loading保留原宽+动词；error显示相邻错误与重试 |
| 次按钮/图标 | surface/text；hover-bg；同样focus；禁用保留原因提示；pending锁定自身；错误不清空上下文 |
| 输入/textarea | panel/text+border；hover strong；focus ring；disabled可读；校验中不跳高；error边框+字段下具体错误 |
| 群/成员/任务行 | 默认无阴影；hover-bg；键盘focus ring；选中active+标线；不可用注明原因；加载局部骨架；失败保留旧数据标记 |
| 页签 | dim；hover text；focus ring；选中accent下划线；不可用提示；加载不替换整页导航 |
| Modal/Drawer | 标题+主体+底部操作；focus trap；Esc关闭非提交态；关闭返回触发点；脏表单确认丢弃；提交失败保留输入 |
| Toast/错误条 | 成功4秒自动消失，错误持续到关闭；aria-live polite；不可作为字段错误唯一载体 |

全站可键盘操作；hover 操作须有常驻菜单/触屏等价入口；菜单上下方向键、Enter、Esc；模态仅一个焦点陷阱。状态不只靠颜色。普通文字对比≥4.5:1，大字/控件边界≥3:1。流式内容不逐 token 朗读，只播报运行开始/结束；目标证据账本用语义列表或表格。Canvas 同步提供可访问成员列表。

## 5. 页面详细设计

### P01 登录、注册、邀请
居中440宽表单，产品名+「连接到此自托管工作台」，用户名/密码/主操作/登录注册切换。错误靠近字段；401 清理失效会话，保留用户名，不缓存密码。邀请页先展示群名/邀请有效性，未登录先登录再回到同一邀请；接受成功进入群。失效邀请提供「联系管理员」，不显示可用接受按钮。桌面 requiresAuth=false，直接启动，不强制 Web 登录。

### P02 无群首页、群导航与建群
无群时显示「尚未加入群」，管理员主操作「创建群」，其他角色显示联系管理员。侧栏上部群名筛选，中部活跃群，底部折叠归档群；未读徽章遵循现有排序。切群保存草稿/位置，群头稳定显示当前群。建群弹窗：名称、project/chat、服务器目录选择（仅project）、预设角色；目录选择器显示服务器根与上级，禁止以浏览器本地文件夹冒充服务器路径。可在允许目录创建子目录，失败原位提示。归档不混同删除，取消归档沿现有权限。

### P03 协作（默认）
从上到下：群头、导航、48高项目摘要条、消息流、输入区。摘要条只在project出现，版本与Goal各一行摘要，默认合计不超过96，点击转对应页面；无数据用「建立版本/创建目标」，可折叠。
消息使用左头像+姓名/角色/时间+正文，不把所有 AI 内容塞成控制面板。每条 run 在关联回复上显示状态、phase、耗时与「详情」。thinking/artifact 默认折叠，点击按需拉取，错误只影响该段。正文超过约12行显示「展开全文」，展开状态保留，代码块有复制。
运行中不抢滚动：距底部≤现有 BOTTOM_THRESHOLD_PX 时跟随；否则显示「N 条新消息」。向上分页保留首条可见消息锚点。最终消息落地去重，不双显流式与持久化副本。
输入区：@成员、/命令、引用预览、OCR/语音等既有入口；发送键沿现有偏好，中文IME composing期间Enter不发。@菜单可搜索，选择存成员ID；/只列现有contrib命令。默认响应者行为保留，未@不统一改为禁止发送。
发送后等待服务端确认；失败保留文本与引用；结果不确定不自动再发。草稿按账号/群隔离；页面离开不清空。OCR是提取文本到草稿，未有附件契约不承诺上传文件作为Agent输入。Live长按说话/气泡播放保留，其媒体权限错误不阻断键盘发送。

### P04 成员、队列、run详情与审批
右栏默认成员：按人/Agent分组，头像、名字、角色、adapter、可用性和「运行中/排队N」。点行打开详情，更多菜单提供权限允许的操作。
队列按当前群 run 列表展示排队/运行/待审阅，再折叠已结束。详情包含 runId、Agent、关联消息、父子关系、phase、错误和审阅状态；层级只展示已有 parentRunId/depth，不杜撰 DAG 调度编辑器。
awaiting_review 显示「待审阅」与通过/驳回；changes_requested 显示「需修改」；completed 不等于已批准。取消运行确认说明「请求停止此任务」，pending时禁重复，状态读回再宣告取消。失败/中断重试确认说明「将创建新的执行，可能再次写入工作区」，保留新旧run链接。
成员表单分人/Agent/chatbot；已有用户、邀请、角色、adapter、模型、工作区按实际类型显示。移除与永久删除文案、权限和影响分开；systemLocked项解释锁定，桌面无真正purge能力时不可标「永久删除」。

### P05 Agent 环境与配置
全局环境页使用 PageLayout：顶部环境状态/刷新，主体为适配器卡或表，自检/CLI路径/版本/模型目录/导入导出；成员专属配置放成员详情页，避免误把全局配置当成本群配置。
导入前展示文件来源、会覆盖哪些配置的现有预览（无预览API时仅说明覆盖风险，不伪造差异比对），确认后执行；导出敏感配置明确提醒。API Key仅密码输入+已设置状态，无明文回显。Connecter远程provider字段按catalog和表单支持保留，不被附件7个key列表误删。CLI不可用区分未检测、未安装、凭据/订阅/地区错误，原文可展开。

### P06 交付（Roadmap / Feature / Task / Version）
PageLayout 顶部标题+当前Git工作区/共享告警+新建版本。次级导航「路线图 / 版本」。
路线图默认列表，行含标题、状态、优先级、负责人/日期（仅对应模型存在时）；Feature点开详情，下方Task复选项，Roadmap关联选择器。排序先提供明确上移/下移或排序字段，不强制开发拖拽。
编排启动显示前置条件、当前状态与暂停/恢复/取消，桌面不可用时保留说明。
版本页左侧版本列表宽240，右侧详情：名称/一句话、What/Who/How、Ask记录入口、Wave时间线、发布摘要。窄屏版本列表变选择器。编辑与运行控制分离；Ask → 批准Wave → 播放/暂停/推进 → 发布按当前服务端状态提供，导航顺序不等于新后端状态机。
没有管理员Agent，Ask/执行按钮说明「先指定管理员Agent」。发布弹窗确认版本、工作区、可选tag及影响；冲突原位显示，不伪造tag成功。未知版本/Wave状态显示原值+只读，禁止猜测下一步。

### P07 目标与证据账本
列表宽280+详情，窄屏列表/详情单栈。详情顶部目标全文、状态、已用轮次/token/时间与预算；缺少已用时间或token时显示「暂不可用」，不假定0。
新建表单：objective、5项budget、每轮审批、自动推进；默认值读取现有契约/实现，自动默认关闭。开始前显示执行者；缺管理员Agent阻止开始并给设置入口。
draft：启动；active：推进一步/暂停/停止；paused：继续（沿现有start行为）/停止；awaiting_approval：批准/停止；completed/aborted：只读账本，不提供「继续」。自动开关只在服务端接受的非终态显示，失败还原。
advance挂起显示「本轮推进中，可离开此页」，禁本goal重复推进；返回后先读回。超时文案「等待超时，后台执行结果待确认」，不可显示「已停止」。暂停/停止说明实际后端语义，操作完成后读回。
账本按轮次倒序：#、verdict、tokensUsed、finishedAt、summary；可展开完整摘要。progress/no_progress/failed/goal_met分别对应进展/无进展/失败/达成。预算终止展示stopReason，审批与run审阅不混为同一按钮。

### P08 内容（Marketing）
campaign列表+详情；创建选择planner/writer、committed/include_uncommitted、base ref。来源模式明确「包含未提交改动」影响。详情展示已有证据、渠道内容、状态、修订反馈框；批准后才允许导出Markdown，未批准的导出按钮注明原因。生成失败保留输入；无证据给项目提交/来源指引，不编造内容。

### P09 场景与扩展
场景默认关闭，点导航才装载；三分区工位/会议/候场，HUD在场/工作/阻塞/完成，成员点选联动既有详情。20名成员不越界，切群释放作用域；动效遵从reduced-motion。始终有返回协作按钮。插件缺失/崩溃显示原因并回聊天。
扩展页按群显示可用/启用状态和视图；iframe只走同源代理。409给启用入口，502给重试和返回协作，503提示内核服务不可用。关闭扩展不清聊天。Live启用/权限/语音授权分开解释；A2A为现有集成能力，本期不发明可视化编排页面。

### P10 可观测、经验与Ops
全局导航下分「日志 / 经验 / 指标 / 运维」。日志过滤level/source与分页，总数与当前条数分开；清空日志强确认。经验保存/查询/删除保留群上下文，删除确认显示标题。
指标缺失不展示0；桌面不支持时注明仅Web。Ops状态展示prod/canary、job、drain。test gate/deploy canary各独立确认，显示目标槽位与任务状态；前台没有「发布生产」新按钮，不将版本Release等同部署。普通成员读权限依后端返回，写操作仅管理员。

### P11 设置、主题与桌面更新
设置分外观、输入行为、运行时、桌面更新（仅桌面）。七主题以名称+预览+选中标记展示，切换不卸载聊天或丢流；保留现有data-theme和存储方式。运行时字段只取RuntimeSettings支持项，保存失败保留表单，成功后反映实际返回值。桌面更新沿现有检查→下载校验→安装动作，未验证资产不标成功；Web不渲染安装入口。

## 6. 通用状态与恢复矩阵
下表适用于P01–P11；具体资源按对应页面请求，不能用整屏错误代替局部错误。

| 状态 | 视觉与行为 | 可恢复动作 |
|---|---|---|
| 默认 | 稳定标题/导航，列表或详情 | 主操作按权限与资源状态 |
| 初次加载 | 3–5行等高骨架，区域aria-busy | 导航和已加载区域可用 |
| 后台刷新 | 保留旧数据，标「刷新中」 | 不重置滚动/编辑 |
| 空 | 描述原因+一个可行入口 | 管理员创建；普通用户联系管理员 |
| 筛选无结果 | 保留筛选与表头 | 清除筛选 |
| 请求失败 | 区域错误+原始错误详情 | 重试只重试读请求 |
| 401 | 会话过期提示，清理订阅并回登录 | 登录后回目标群；不保留敏感输入 |
| 403 | 保留只读内容+「无操作权限」 | 联系管理员；不反复重试写请求 |
| 404 | 资源已移除/不可见 | 返回列表并刷新 |
| 409 | 冲突/状态已变化 | 读回资源后重新决定 |
| 503 | 服务不可用 | 局部重试；聊天等可用区域保留 |
| 离线/重连 | 沿现有重连静默/发布策略，持续异常再横幅 | 草稿保留，禁止静默排队自动发写请求 |
| 未知状态 | 原始值+保守只读 | 刷新/错误详情，不崩溃 |
| 保存中 | 锁定对应提交，按钮保留宽度 | 失败保留输入，成功关闭并恢复焦点 |

## 7. 页面评审交付
后续实现必须输出1440×900、1024×768、390×844三种视口主路径截图，另测320宽及720分界、200%缩放、粗指针。七主题均覆盖主壳、表单、审批、错误、禁用与聚焦。截图是未来验收要求，本次没有声称已经渲染或检查对比度。

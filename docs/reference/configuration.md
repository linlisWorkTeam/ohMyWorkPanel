# Reference：配置

## 已确认的开发配置

| 配置 | 当前值或规则 | 适用场景 |
| --- | --- | --- |
| Vite 开发地址 | `http://127.0.0.1:1420` | `pnpm dev`、Tauri 开发模式 |
| 前端环境变量前缀 | `VITE_`、`TAURI_` | Vite 构建时读取 |
| 适配器目录环境变量 | `OHMYWORKPANEL_ADAPTER_ROOTS` | 扫描额外的 `*.adapter.json` |

## 数据

桌面模式使用 Tauri 应用数据目录中的 SQLite 数据库。Web 部署的数据目录由部署环境决定；不要把测试数据目录和生产数据目录混用。

## 安全提示

- 不要把 API Key、JWT、CLI 登录态或 SQLite 数据库提交到 Git。
- 生产环境配置应通过部署环境提供，不要写入前端源码或公开文档示例。
- 修改配置后请重新运行与配置相关的测试和启动检查。

# V1.3.0 · S1 实现计划：版本页壳（Version Tab Shell）

- 日期：2026-08-06
- 依据：设计稿 `docs/superpowers/specs/2026-08-06-workpanel-v1.3.0-workflow-era-design.md` + 技术评审 `docs/superpowers/specs/2026-08-06-v1.3.0-tech-review.md`（产品审稿 4 必改 6 建议已并入）
- 范围：S1 只做「版本页签 + Git Tag 时间线 + 去旧项目页签入口」，只读为主
- 铁律：commit 前灰度测试 + 更新 docs；灰度通过后由 root approve 才 promote 生产

## 交付物（验收标准）

1. 顶栏新增「版本」页签，与「聊天」平级；「项目管理」入口从顶栏移除（ProjectWorkflowView 代码保留不删）
2. 版本页展示 workspace Git Tag 时间线：最新版本展开、历史版本折叠
3. 无 Tag 时显示虚拟 Tag（按最近 commit 生成），并展示 `finish-last-round` 状态（git HEAD 停在最新 tag 点）
4. 新建版本入口（按钮占位，S2 接表单）；高危操作仅群主+管理员可见可点
5. `git_inspect` 平台侧能力（30s 缓存 + 虚拟 Tag）

## 任务拆分（实现者按序执行）

### T1 后端：git_inspect 命令（平台侧，净新增）
- 位置：`src-tauri/src/`（建议新文件 `git_inspect.rs`，挂到 commands.rs）
- 实现：`Command::new("git")` 读 workspace 的 `tag --sort=-creatordate` + `log --oneline -20`
- 缓存：进程内存 `Mutex<HashMap<PathBuf,(Instant, GitSnapshot)>>`，TTL 30s
- 虚拟 Tag：无 tag 时按最新 commit 生成 `v0.0.0-draft` 虚拟项（标记 `virtual: true`）
- 边界：workspace 非 git 仓库 → 返回空列表 + `isGitRepo: false`（前端显示引导）
- 单测：`test:gate` 增补（临时 git 仓库 fixture：有 tag/无 tag/HEAD 停在 tag 三种情况）

### T2 后端：project_versions 表 + 只读 API
- 新表 `project_versions`（id, group_id, tag_name, git_commit, kind: real|virtual, status: active|finished, created_at, created_by）
- API：`GET /api/projects/{id}/versions`（合并 git_inspect 结果 + 表数据）；写操作（新建/导入）仅 S2，S1 只留权限校验骨架
- 权限：非管理员写请求一律 403（S1 就落地）

### T3 前端：版本页签 UI
- `App.tsx`：`mainView` 增加 `"versions"`；顶栏 tab 加「版本」按钮（与聊天平级）；移除「项目管理」按钮（:1208）
- 新组件 `VersionView.tsx`（仿 Langraph 简洁时间线）：
  - 版本卡片：最新展开（Tag 名/commit/时间/状态徽标），历史折叠（点击展开）
  - `finish-last-round` 态：HEAD 停在 tag → 显示「本轮已完成，可新建版本」横幅
  - 新建版本按钮（管理员可见，S1 点击提示「S2 开放」或直接禁用态）
- `ProjectWorkflowView` 保留文件，仅不再渲染（:1083 条件移除）

### T4 灰度验证（commit 前必做）
- `pnpm run test:gate` 通过
- `scripts/deploy-canary.sh` 部署 :8081，跑 `scripts/canary-announce-a2a.sh` 公告
- 手动清单（对齐 release-checklist §F）：

  - [ ] 版本页签可见，Tag 时间线渲染正确（有 tag 仓库）
  - [ ] 无 tag 仓库显示虚拟 Tag + 引导
  - [ ] 非管理员看不到新建入口；管理员可见
  - [ ] 「项目管理」入口已消失，聊天/版本/Live 切换正常
  - [ ] git_inspect 二次进入 <30s 内不重复跑 git（缓存生效）
- 更新 `docs/version-pipeline.md`（S1 完成状态）+ 本计划文档验收打勾

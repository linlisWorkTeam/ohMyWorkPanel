# Documentation Localization

[简体中文](i18n.md) | **English**

This project maintains documentation translations as Markdown files. It does not add a runtime internationalization framework or a documentation build tool.

## File Convention

- `README.md`: default Chinese entry point; `README.en.md`: English entry point;
- `docs/index.md`: Chinese documentation index; `docs/index.en.md`: English documentation index;
- Tutorials and How-to guides keep a matching `.en.md` file in the same directory, such as `quickstart.md` and `quickstart.en.md`;
- Every language file must provide links to its other language at the top.

## Translation Rules

1. Keep the same section order, commands, screenshots, and link targets in both languages.
2. Keep product names, CLI names, commands, environment variables, paths, and API fields unchanged.
3. New user-facing tutorials and How-to guides must be added in both Chinese and English.
4. Do not invent functionality that is not available in the current version. Use `<!-- TODO: 根据项目实际补充 -->` for uncertain content.
5. Before a release, check that installation commands, version numbers, screenshots, and risk notices match in both languages.

## Maintenance Workflow

Update the default Chinese document first, then update the English counterpart. Check relative links, code blocks, and image paths, and state in the PR whether both languages were verified.

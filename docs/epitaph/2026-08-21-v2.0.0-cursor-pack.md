# Epitaph: v2.0.0 — Cursor Agent 环境包 + tag

## Built this session
- 脱敏配置包 `docs/releases/v2.0.0/cursor-agent.bundle.json`（仅 cursor；默认 grok-4.6；不含 auth/邮箱/二进制）。
- 生成脚本 `scripts/pack-cursor-agent.sh`。
- `package.json` / Cargo / `tauri.conf.json` → **2.0.0**；流水线阶段 6。
- git tag **`v2.0.0`** 钉在含本包的 commit（不是把旧 HEAD 误打成 1.3.0）。

## Locked product decisions
| 项 | 选择 |
|---|---|
| 打进 Git | 配置配方 + 文档 |
| 不打进 Git | cursor-agent 二进制、Cursor 登录态、API key |
| 导入后 | 仍须本机 `agent`/`cursor-agent` 已登录 |
| 策略快照 | 含本机 `approvalMode=unrestricted`；导入他机前请审 |

## Do not regress
- 配置包不得含 `authId` / `authCacheKey` / 邮箱。
- 勿把 dsh 内核当编译期依赖。
- Agent 不得无批准 promote。

## Locked product decisions

| 项 | 选择 |

| 静态前端 | `OHMYWORKPANEL_WEB_DIST=/AI/ohMyWorkPanel/dist` |

## Known pitfalls

- 机器仅约 **1.8GB RAM**：`vite build` / `cargo build --release` 易 OOM；务必 `CARGO_BUILD_JOBS=1`，必要时 `sync && echo 3 > /proc/sys/vm/drop_caches`，Node 用 `NODE_OPTIONS=--max-old-space-size=1024`
- shell 里 `cp` 可能是交互别名；覆盖安装用 `/bin/cp -f`
- 大量源码改动仍 **未提交**（Experience/Logs/event_sender/logger/proxy 等）
- preset-roles 中文在终端 curl 下可能显示乱码（库内/前端正常即可）

## How to run / verify

```bash
# 服务（生产）
systemctl status ohmyworkpanel.service ohmyworkpanel-proxy.service
curl -sS -o /dev/null -w '%{http_code}\n' http://127.0.0.1:8080/
curl -sS -o /dev/null -w '%{http_code}\n' http://127.0.0.1:9090/

# 重建（低内存）
cd /AI/ohMyWorkPanel
NODE_OPTIONS=--max-old-space-size=1024 pnpm run build:web
cd src-tauri && CARGO_BUILD_JOBS=1 cargo build --release --no-default-features --bin ohmyworkpanel-server
/bin/cp -f target/release/ohmyworkpanel-server /usr/local/bin/
systemctl restart ohmyworkpanel.service

# 登录冒烟（可现场 register）
curl -sS -X POST http://127.0.0.1:8080/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"startcheck","password":"startcheck123"}'
```

## Do not regress

- systemd 环境变量 `OHMYWORKPANEL_DATA_DIR` / `OHMYWORKPANEL_WEB_DIST` 路径
- Web 构建必须走 `vite.config.web.ts`（Tauri stub alias）
- `EventSender` 双通道（Tauri/Web）与 scheduler 集成
- logs / experiences 路由与 SQLite 表

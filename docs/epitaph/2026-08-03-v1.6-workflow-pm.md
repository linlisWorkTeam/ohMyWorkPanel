# Epitaph: 项目工作流视图 / 服务端路径 / 群公告 / Ops / 性能

## Built this session

- **服务端路径 (2B)**: `fs_browse` + `GET /api/fs/list` + `POST /api/fs/mkdir`；建群用 `ServerPathPicker`，可浏览已有目录或在其下新建文件夹后选用
- **群公告**: `groups.announcement`；prompt 注入 + 同步 `.cursor/rules/group-announcement.mdc`
- **主视图**: 群名旁 聊天/项目 切换；`ProjectWorkflowView`（roadmap 进度带、Agent 泳道、看板、公告、Ops）
- **Ops (1A)**: test-gate / release-status / deploy-canary API；Promote 不进 UI
- **性能**: message_delta 按 index 局部更新；run_status 局部 patch；MessageBubble memo；消息窗口 200
- **验证**: Rust 21/21；Vitest 2/2；`tsc -b` 通过

## Locked product decisions

| 项 | 选择 |
|---|---|
| 路径 | 服务器绝对路径；可 list 已有目录，或 mkdir 新建后选用（禁 `/` 下直接建） |
| Ops | 进产品；promote 仍用脚本 |
| 公告 | DB 权威 + prompt + 可选写 workspace rules |

## Do not regress

- 生产 DB / promote 不进 UI
- 同 Agent 串行
- canary 部署仍跑 test-gate
- 测试不写生产 `data/`

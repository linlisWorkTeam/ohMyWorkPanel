# Epitaph: Agent 流式分区 + 同 Agent 串行 + Cursor Session 复用

## Built this session

- **流式分区**: `messages.content` 存 JSON parts（`thinking` / `artifact` / `final`）；`ChatEvent.channel` 标记 delta；旧纯文本兼容为 final
- **同 Agent 串行**: `schedule_group` 跳过已有 `running` 的同 `agent_member_id`；跨 Agent 仍受 `max_concurrent_runs`
- **Cursor session**: `agent_profiles.cli_session_id` + `--resume`；有 session 时用短 prompt；失败清空后重试一次；`--stream-partial-output`
- **前端**: 同气泡分区（思考可折叠、中间产物、最终回复）；有输出即渲染，减少「排队/回应中」空气泡
- **验证**: `cargo test --no-default-features --lib` → 11/11；`vitest` messageContent + mentions 通过
- **发布**: 仅灰度 `:8081`（未 promote）

## Known pitfalls

- CLI JSON 形态漂移时分区可能不准 → 默认定 `final`
- resume 字段名依赖启发式；失败会清 session 重试
- 本 CLI 人工对话不会自动回写 ohMyWorkPanel 群（渠道不同）
- **Cursor 无响应（2026-08-01 热修）**: 群 `workspace_path=/` 会让 CLI 空转至超时；assistant 全量快照若当 delta 追加会爆消息体；超长 prompt 触发 `Argument list too long`。已改为拒绝 `/`、assistant 无 `timestamp_ms`/`result` 用 replace、历史截断。

# Epitaph: v2.1.0 壳层扩展 + 七主题 + 微信对话

## Built this session

Frontend-only v2.1.0 implementation (no IPC/schema/prod):

- `src/contrib/*` contribution registry (Base four right tabs, composer tools, message actions). Fake Extend tabs append without changing App unions.
- Right rail: 成员 / 队列 / 详情 / 设置 + Extend tabs. Live docks to a second column (`sessionStorage` `lp.rightDock.v1`).
- Header icon cluster (🎨⚙? / extension initials) removed. Settings (appearance / runtime / group) live in the right **设置** tab. Rail ◇ still opens Agent 配置. WAVE bar still opens versions.
- Chat: WeChat-like bubbles; copy/quote/speak/retry in `ContextActionMenu` (fixed overlay). Only **停止** stays on streaming bubbles. Quote sends a `「引用 …」` prefix (no schema).
- Members: roster row + ⋯ / right-click menu keeps 检测 / 设管理 / 移除 / 模型 / DSH.
- Theme `minimal` added; `ThemeSwitcher` is seven equal stage cards.
- Brand / ThemeSwitcher / HeaderThemePop keep-alive wrappers remain (HeaderThemePop rendered with `open={false}`).

**Not done:** git tag `v2.1.0`, canary deploy, prod promote. Cordis runtime.

## Locked product decisions

- Slash remains `/board /approve /wave` only.
- No thumbs, no Slack threads, no quoteMessageId column this release.
- Overlay menus must not change list height (replaces always-visible `.m-actions` implementation).
- Do not `systemctl` prod or `promote-canary` without human `approve-prod-release.sh`.

## Known pitfalls

- Some minifiers drop JSX-only theme imports → empty `#root`. Keep value-bind wrappers.
- Entering a group with unreadCount jumps toward `len - unread` (approximation; no first-unread id).
- Docked Live shares the existing right pane width; narrow windows undock (`CONCEDE_RIGHT`).

## Do not regress

- `themeChromeKeepAlive` value-imports.
- Four Base tab ids: `core.members|queue|details|settings`.
- Member detect/admin/remove exist in the menu, not as row buttons.
- Streaming bubbles expose 停止; idle bubbles do not show a copy row.

# Epitaph: 自动化测试策略 + canary 门禁脚手架

## Built this session

- **策略文档**: [`docs/testing-strategy.md`](../testing-strategy.md) — 金字塔、覆盖矩阵、分期、内存约束、Do not regress
- **门禁脚本**: `scripts/test-gate.sh`（Vitest + `cargo test --no-default-features --lib`）
- **绑 canary**: `deploy-canary.sh` 在构建前强制跑门禁；`BUILD=skip` 仍跑门禁
- **破窗**: `OHMYWORKPANEL_SKIP_TEST_GATE=1`（日常禁止）
- **骨架单测**: `scheduler::plan_queued_starts`（同 Agent 串行）+ `auth` password/JWT roundtrip
- **验证**: `bash scripts/test-gate.sh` → Vitest 2/2、Rust 16/16

## Locked product decisions

| 项 | 选择 |
|---|---|
| 交付 | 策略文档 + 最小脚手架（非全量集成/E2E） |

| 真 CLI smoke | 不进门禁 |

## Known pitfalls

- 对整个 shell 设过紧 `ulimit -v` 会让 Vitest Wasm OOM；门禁只限 cargo 子进程
- argon2 单测稍慢（~数秒），属正常

## How to run / verify

```bash
pnpm run test:gate
# 或
./scripts/test-gate.sh
```

## Do not regress

- canary 部署前必须过门禁（除非破窗 env）
- 测试不得写生产 `data/`
- 同 Agent 串行语义（`plan_queued_starts`）

# Epitaph: v1.7 Run phases / Chatbot / workspace sandbox / keep-alive

## Built this session

- **OOM root cause**: Kill was host memory pressure (~1.8GB), not a wrong app `ulimit` alone. Concurrent Cursor agent + cargo/rustc + openclaw pushed RSS over the edge. Adding `reqwest` for chatbot made rustc heavier.
- **Mitigation**: Chatbot HTTP via system `curl` (no `reqwest` dep). `test-gate.sh` runs Vitest with `--maxWorkers=1` and isolates cargo `ulimit -v` in a child bash (never apply `ulimit -v` to the whole gate — Vitest Wasm OOMs).
- **Run phases**: `task_runs.phase` + WS `run_status` carries `phase`/`elapsedMs`/`totalMs`; frontend patches runs live and shows phase on bubbles/lanes.
- **Chatbot member**: `kind=chatbot`, one per group; model fixed `deepseek-v4-flash`; providers `opencode-go` | `deepseek`; API key required at add-time (DB only, never git).
- **Workspace**: group path editable; agent path must stay under group (`.linlis/agents/<id>` default); UI via `ServerPathPicker` in project view.
- **Memory**: `.linlis` layout; experiences append group/agent memory; scheduler injects excerpt into prompts.
- **Keep-alive**: setting admin agent sets `keep_alive=1`; 300s loop updates warm status for cursor admin sessions.
- **Verify**: `pnpm run test:gate` green (chatbot provider unit tests + memory sandbox + 2 vitest). Committed with realtime `wss` fix; canary `:8081` redeployed with chatbot; prod `:8080` untouched.

## Known pitfalls

- Parent-shell `ulimit -v` before Vitest → Wasm OOM (`ho: command not found` / allocate failures).
- Do not reintroduce `reqwest` on this host without checking free RAM.
- Canary DB ≠ prod; chatbot keys must be re-entered on canary if needed.

## How to run / verify

```bash
unset OHMYWORKPANEL_SKIP_TEST_GATE
export CARGO_BUILD_JOBS=1 NODE_OPTIONS=--max-old-space-size=768
pnpm run test:gate
sync; echo 3 > /proc/sys/vm/drop_caches 2>/dev/null || true
/AI/ohMyWorkPanel/scripts/deploy-canary.sh
curl -sS -o /dev/null -w '%{http_code}\n' http://127.0.0.1:8081/
```

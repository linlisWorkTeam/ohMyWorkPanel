WorkPanel × DeepSeek Harness — 交互原型说明

不是静态图：这是「三栏 AppFrame + token 设计系统 + 招牌 UX」的可交互演示。每项都对应 dsh 里真实存在的组件，也是 WorkPanel 借鉴的目标。

#交互 / 设计对应 dsh 组件本机怎么试
1三栏拖拽调宽（带最小宽度约束）ui-layout ResizablePane拖中缝 / 右缝分界
2左栏折叠 → 56px 控制轨ui-layout rail底部「左栏」或拖到最窄
3右栏成员面板可关到 0ui-details 折叠头部 ☰ 或底部「右栏」
4窄屏让步（右先收 → 左再轨化）ui-layout concession拖「视口宽」滑块变窄 / 一键看效果
5主题 = alias token，组件只用语义色ui-theme design-platform🎨 或底部主题按钮换 6 套
6goal bar：Wave 目标常驻（上移）ui-goal中栏头部下方那条
7Agent 工作 = parts + todo 行 + tool 行ui-trajectory / todo 行 / ui-tool输入一句话点发送
8消息操作 / 反馈（复制·赞·踩·朗读）ui-message-feedback悬浮任意消息气泡
9队列卡片 + 审批内联卡ui-jobs / approval-composer右栏「队列」页签
10composer：@ 提及 / 斜杠命令 / 草稿ui-composer输入框敲 @ 或 / 试试
11成员 = Agent（执行中·排队·模型·工作区）ui-sidebar / ui-subagent右栏「成员」「详情」页签

设计约束照搬 dsh 心智：几何临时（面板宽/折叠只存 localStorage，不进 DB）、组件只用 --lp-alias-* 语义 token、主题只是 alias 供给器。业务模型仍是「多群多 Agent 群聊」，不退回单人会话。

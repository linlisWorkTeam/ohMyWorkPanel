# Documentation Localization

[简体中文](i18n.md) | [English](i18n.en.md)

本项目使用 Markdown 文件维护文档多语言版本，不引入运行时国际化框架或文档构建工具。

## 文件约定

- `README.md`：默认中文入口；`README.en.md`：英文入口；
- `docs/index.md`：中文文档首页；`docs/index.en.md`：英文文档首页；
- 使用指南和教程在同一目录下维护同名 `.en.md` 文件，例如 `quickstart.md` 与 `quickstart.en.md`；
- 每个语言文件顶部必须提供互相跳转的语言链接。

## 翻译规则

1. 中文和英文文件保持相同的章节顺序、代码命令、截图和链接目标。
2. 产品名称、CLI 名称、命令、环境变量、路径和 API 字段保持原样，不做意译。
3. 面向用户的新增教程或 How-to 必须同时提供中英文版本。
4. 翻译不应虚构当前版本不存在的功能；不确定内容使用 `<!-- TODO: 根据项目实际补充 -->`。
5. 发布版本前检查两种语言的安装命令、版本号、截图和风险提示是否同步。

## 维护方式

先更新默认中文文档，再同步更新英文文件。完成后检查相对链接、代码块和图片路径，并在 PR 中说明两种语言是否都已验证。

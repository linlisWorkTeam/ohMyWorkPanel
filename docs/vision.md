# Vision

ohMyWorkPanel 是一个**本地优先的多 Agent 群聊桌面应用**，让用户在自己的机器上组建 AI Agent 协作团队。

## 核心理念

- **本地执行**：Agent 直接在本机工作目录中运行，数据不离开本地
- **群聊式协作**：像群聊一样 `@` 提及 Agent，任务自然流转
- **多 CLI 生态**：接入 Codex / Claude Code / OpenCode / Cursor 等已登录的 CLI，复用现有授权
- **管理员委派**：Agent 可设为管理员，由它解析输出中的 `@` 并将子任务派给其他 Agent

## 产品形态

Tauri 2 桌面应用，前端 React 19，后端 Rust + SQLite。启动即用，无需部署服务端。

## 长期方向

1. **Agent 运行沙箱与审核**：命令白名单、危险操作确认
2. **群聊模板**：常见协作场景预置 Agent 配置
3. **历史回溯与对比**：任务重放、分支对比
4. **跨机器同步**：可选云端备份群聊与任务状态
5. **Agent 商城**：社区贡献角色定义与 prompt 模板

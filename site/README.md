# site/ — 项目主页源码

这是 <https://linlisworkteam.github.io/ohMyWorkPanel/> 的源码。

- 单文件静态页面：`site/index.html`（内联 CSS、内联 SVG 图标，无外部依赖）
- 线上由 `gh-pages` 分支提供，GitHub Pages 源设置为 `gh-pages` / 根目录
- 更新流程：改 `site/index.html` → 复制到 `gh-pages` 分支根目录的 `index.html` → push

内容结构：Hero 定位 → 五项核心机制 → 6 阶段流程 → 四层架构 → 执行器与安全边界 → 快速开始。
